# DotNetDemos

A collection of small .NET projects I build to practice and apply what I'm learning. Each project — or each feature inside a project — is tied to a concept I've just studied, so this repo doubles as a hands-on learning log rather than a portfolio of "finished" apps.

## What this is for

Rather than just reading about a concept, I try to implement it in real code right after I learn it. That means:

- New demo projects get added here over time as I learn new things.
- Projects may keep evolving after they're first added — expect ongoing changes.
- Code reflects where I was in my learning journey at the time, not necessarily "best practice" end-to-end.

## Topics I'm practicing

- Entity Framework Core
- Web APIs (Controllers) and Minimal APIs
- Authentication / Authorization
- Object-Oriented Programming (OOP)
- Clean Architecture
- Global exception handling
- ...and more, as I go
